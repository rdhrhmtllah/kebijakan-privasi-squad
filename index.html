2. Izin yang diminta aplikasi

  • Kamera: presensi wajah dan pemindaian kode.
  • Lokasi: validasi lokasi presensi, hanya saat aplikasi terbuka.
  • Notifikasi: mengirim pemberitahuan kerja.
  • Biometrik perangkat (sidik jari atau PIN): membuka kunci aplikasi. Data sidik jari tetap di perangkat Anda dan tidak dikirim ke kami.

Anda dapat mencabut izin kapan saja di pengaturan perangkat. Tanpa izin kamera atau lokasi, presensi wajah tidak dapat dilakukan.

3. Dasar pemrosesan

Kami memproses data ini untuk melaksanakan hubungan kerja (presensi, cuti, lembur, penggajian), memenuhi kewajiban hukum ketenagakerjaan, dan menjaga keamanan sistem. Data biometrik wajah diproses dengan persetujuan Anda yang diberikan saat mendaftarkan wajah, sesuai Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi.

4. Dengan siapa data dibagikan

  • Atasan, HR, dan administrator Perusahaan yang berwenang, sebatas keperluan kerja.
  • Penyedia layanan yang memproses atas nama kami: Google (Firebase Cloud Messaging untuk notifikasi, Google Sign-In untuk pendaftaran perangkat, dan penyimpanan awan untuk berkas). Mereka tidak boleh memakai data Anda untuk tujuan lain.
  • Pihak berwenang, bila diwajibkan hukum.

Kami tidak menjual atau menyewakan data pribadi Anda.

5. Keamanan

Seluruh komunikasi aplikasi dengan server dienkripsi (HTTPS, dan sertifikat klien untuk server mobile). Setiap perangkat harus didaftarkan dan disetujui administrator sebelum dapat dipakai. Akses data dibatasi sesuai peran. Foto presensi disimpan di penyimpanan awan dengan akses terbatas.
